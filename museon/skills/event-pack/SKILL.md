# 活動洞察包

查看某個客戶專案的活動洞察包。不帶 section 先看 14 個項目的目錄與資料截止時間，再帶 section 逐項看內容；內容分頁時用 next_cursor 取下一頁，續頁失敗就不帶 cursor 重新取第 1 頁。資料來自公開的網路討論與活動資料，還沒採集到的項目會明說「資料尚未採集」，不會編造。需要先有該專案資料夾的需求摘要（至少有品牌或品類）。例：『幫我看 A 品牌這個專案的活動洞察』。

## 何時用

會員要看某個客戶專案的活動洞察時用。只使用當次連線實際列出且本人已授權的工具；沒列出就說這項目前尚未開放，不假稱已執行。

## 怎麼呼叫

呼叫 MuseON 的 `museon.event.pack.read`：`project_ref` 必填，是會員 MuseON 專案資料夾的編號（p_ 開頭），不要猜；不帶 `section` 先看目錄，再帶 `section` 逐項看；內容分頁用 `next_cursor` 取下一頁。

## 常見回覆

- 這個專案資料夾還沒有可用的需求摘要（至少要有品牌或品類），或找不到這個資料夾。請先用 museon.method.step 跑需求釐清，把品牌或品類補進摘要，再回來看洞察。
- 洞察資料暫時無法取得，不是沒有資料。請稍後再試，不要把這次當成「沒有相關討論」。
- 續頁憑證已過期或不再適用。請不帶 cursor，重新取得這個項目的第 1 頁。

需求釐清見 `skills/intake/SKILL.md`；總入口見 `skills/museon/SKILL.md`。

## 連線與完成條件

只使用當次連線實際列出且本人已授權的 MCP 能力；method 識別字是用途對照，不是固定工具清單。方法不可用時說明尚未接通，不假稱已執行。方法內容留主機，依工具當次回傳繼續。外掛只查回會員本人在 MuseON 已有且來源明確的自有紀錄；來源不明或混合資料不讀取。不讀取或擷取 Claude 的記憶、聊天歷史、對話摘要或使用者檔案；不以對話建立畫像或改變跨次行為。會員明確要求記下筆記、摘要、目標或待辦時，才可用 museon.secretary.record.write 保存；沒開口就不存。保存關閉時，照工具回應告知會員，不自行繞過。不得呼叫查後名片整理能力；本人授權不解除上述讀取、畫像與名片整理限制。對外動作依本人當次授權，工具成功才報完成。
