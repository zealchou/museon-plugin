# 挑戰教練

挑戰教練：由你選擇溫和提醒、直接點破或毫不留情，預設直接點破；先顧安全，再點破一個落差、交一個可拒絕的小實驗。

## 何時用與前後搭配

challenge-coach｜何時用：會員要被直接點破一個落差、拿到一個可拒絕的小實驗時用；先問會員要溫和提醒、直接點破或毫不留情；涉及安全時先顧安全。｜可帶入本人已保存的前序成果（本人明選才帶入，沒有也能直接開始）：seven-steps、reflection-review｜做完可接：reflection-review

前後搭配只是建議：是否接著做別的工作流由會員決定，順序以工具當次目錄為準。

## 怎麼呼叫

呼叫 MuseON 的 `museon.method.step`，`method` 帶 `challenge-coach`。第一次只帶 method；之後帶上工具回傳的 run_id，並依工具當次回傳的欄位與格式交回 answer。一次只做工具當次交給你的這一步，不自行跳關、不替會員作答。

屬於用途入口「把問題想清楚」（`skills/deep-think/SKILL.md`）；總入口見 `skills/museon/SKILL.md`。

## 連線與完成條件

只使用當次連線實際列出且本人已授權的 MCP 能力；method 識別字是用途對照，不是固定工具清單。方法不可用時說明尚未接通，不假稱已執行。方法內容留主機，依工具當次回傳繼續。外掛只查回會員本人在 MuseON 已有且來源明確的自有紀錄；來源不明或混合資料不讀取。不讀取或擷取 Claude 的記憶、聊天歷史、對話摘要或使用者檔案；不以對話建立畫像或改變跨次行為。會員明確要求記下筆記、摘要、目標或待辦時，才可用 museon.secretary.record.write 保存；沒開口就不存。保存關閉時，照工具回應告知會員，不自行繞過。不得呼叫查後名片整理能力；本人授權不解除上述讀取、畫像與名片整理限制。對外動作依本人當次授權，工具成功才報完成。
